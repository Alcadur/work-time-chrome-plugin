## Jira Time Tracker

### How to install

- Clone the repository
- Go to: chrome://extensions/
- Enable developer mode
- Click on "Load unpacked" and select the cloned repository folder

### Features

- Manual task name
- Automatic task name from Jira
- Edit / delete log
- Log history

### How to use

#### Manual time log

- Click on the extension icon
- Enter task name
- _(optional)_ Select start time
- Click "Begin"
- Do the work :) 
- Click "Finish"

[![s-E8Vbg-Za-XX.gif](https://i.postimg.cc/TPmh0VSJ/s-E8Vbg-Za-XX.gif)](https://postimg.cc/zLzJXgqy)

#### Automatic time log

- Make sure you are on a Jira page with open the task
- Click on the extension icon
- Click "Begin"
- Do the work :) 
- Click "Finish"

##### How does it work?

Script is automatically detecting the task name from the Jira page and task number from URL.

[![chrome-11yhimeqqi.png](https://i.postimg.cc/N0VSsTf3/chrome-11yhimeqqi.png)](https://postimg.cc/Z98VjWNH)

[![chrome-An5t-KC6e-SY.png](https://i.postimg.cc/cC7bBbMJ/chrome-An5t-KC6e-SY.png)](https://postimg.cc/8f541wY8)

It works on all Jira pages, so when you open the extension on a page that is not a task, the title may be unpredictable :)  

[![chrome-q2w-EHx-Jl-Q7.png](https://i.postimg.cc/FzvPzx55/chrome-q2w-EHx-Jl-Q7.png)](https://postimg.cc/MMs0rVpd)

#### Log Edit

- Click on the extension icon
- Click the "Edit" button from the right menu
- Edit the log
- Save

[![6SR3Wje-Hrv.gif](https://i.postimg.cc/50SB7dTW/6SR3Wje-Hrv.gif)](https://postimg.cc/5YjQyGfs)

#### Log delete

- Click on the extension icon
- Click the "Delete" button from the right menu
- Confirm action

[![chrome-Qq-KULCz2AU.gif](https://i.postimg.cc/KzfT77ks/chrome-Qq-KULCz2AU.gif)](https://postimg.cc/ygJWsZTF)

#### Log History

- Click on the extension icon
- Click the "Open log list" button
- Select date
- (optional) Group tasks by name
